This project aims to prevent sleep or deep sleep states of drives, writing in a loop 1 byte in a file every 3 seconds. 

How to use the app:

1- It's a portable app, so download the released exe where you want

2- Execute KeepAliveDrive.exe as your normal user

3- Enter the drive letter as requested

4- Enjoy the device with no sleep during listening music, watching films, playing...


To change the letter of the device you want prevent sleep, go to %localuserapp%\KeepAliveDrive.txt and change there manually
